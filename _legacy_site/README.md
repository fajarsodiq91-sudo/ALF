# PT Alfajar Logic Futura — Website

Static company website for PT Alfajar Logic Futura (IT consulting, data analytics,
business intelligence, AI, and corporate training).

## Structure

- `index.html` — main landing page
- `style.css` — site styles
- `script.js` — site behavior
- `thank-you.html` — post-contact-form confirmation page

## Notes

- The contact form submits to [formsubmit.co](https://formsubmit.co); no backend is required.
- Image assets referenced under `assets/images/` and `assets/icons/` are not yet
  present in this repo and need to be added.
